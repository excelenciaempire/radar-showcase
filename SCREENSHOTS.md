# Interface capture provenance

The source is Radar’s actual internal workspace UI, loaded on 2026-11-03 from the existing isolated design fixture. The fixture uses temporary test storage, no credentials and no production writes. The visible QA product, library counts and saved investigation are synthetic test data, not measurements of the real catalog.

Radar’s native light theme was selected. The captured DOM’s interface labels and fixture text were translated locally into English for this portfolio. This does not establish that the deployed application has an English-language setting. The QA notice remains visible, moved to the bottom of the capture so it does not cover controls.

## Capture method

The browser’s native snapshot tool timed out. The image was therefore rendered from a frozen copy of the loaded interface DOM and its styles, with fonts retained. Application scripts, hidden inputs and live connections were excluded. This is a static interface view, not a runnable app, an end-to-end test result or a newly verified product release.
